# ALIGN3 design specification

Fixed deterministic seeds: DEV 431730; EVAL 851906. Four query frames each have lower-first and upper-first wordings. Within a block the candidate full texts, entity, property, exact interval, gold identity, inclusion, frame, arithmetic operator positions, numeral-span widths, character length and space-word count are fixed. One pair of operands changes. Right-excluded blocks vary x minus (x-L); left-excluded blocks vary x plus (U-x). The other bound uses a fixed two-operand expression. Gold is strictly interior; wrong is the excluded endpoint. All numbers are positive integers, first operands three digits and complements two digits. Neutral positions cycle below both, between, above both by block index. Selection has no model feedback, max 200 draws/block; every rejected parameter set is logged.

DEV: 4 blocks, one per template, 24 queries. EVAL: generated only after DEV QA, 12 blocks, 3 instances per shared template, 72 queries; 6 blocks per exclusion direction. All six queries per block stay in one split. Synthetic, template_shared_exploratory EVAL. Only EVAL scored. The altered numeral spans include both the leading operand and compensating operand. Numeral alignment is complete decimal-span equality; substring/subword overlap remains possible and is logged separately. Tokenizer length may vary without character-length differences. No truncation, score filtering or inference of internal neural mechanisms. The manipulation is not a deployable query rewrite because construction uses private answer roles.

Analysis fixed before target scoring: gold-minus-wrong raw margin; two wordings/block, three instances/template, four templates equally weighted. Three contrasts GOLD-WRONG, NEUTRAL-WRONG, GOLD-NEUTRAL, exact ties and near ties ±1e-6/±1e-5; candidate order tolerance inherited 1e-4. Per-model scales stay separate. Descriptive leave-one-template-out; no inferential significance test or new power claim. Every condition, block and model retained regardless of direction.
