# Public GitHub publication

This directory is the upload payload. Its parent directory contains local verification outputs and is not part of the repository. Upload only this directory. Do not upload its parent project, credentials, caches, model weights, environment folders, private preparation maps, or prior manuscript drafts.

Create a new repository with **Public** visibility and use `main` as its default branch. Do not overwrite an existing repository without confirming that it is the intended destination. The latest user instruction authorizes public visibility.

If GitHub Desktop is used, add this initialized local repository, select **Publish repository**, and disable **Keep this code private**. See [GitHub's existing-project instructions](https://docs.github.com/en/desktop/adding-and-cloning-repositories/adding-an-existing-project-to-github-using-github-desktop).

Authentication should use GitHub's login/authorization flow. Do not put a password or personal access token in repository files, remote URLs, screenshots, or chat. The payload needs no API credential. The final receipt records the actual destination and visibility only after verification.
